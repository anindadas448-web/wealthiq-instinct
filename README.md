# WealthIQ · Instinct page

One question: how deep a fall could you sit through? Steady, Measured, Bold or Fearless, against the Nifty 50 since 2000.

- V1 Stacked: a real Nifty fall (2015–17) on ₹10 Cr, centred; choosing a line reshapes the whole path to that depth, with a GPS marker at the low.
- V2 Split: each fall as a group of two-month candles, with the four bands behind them.
